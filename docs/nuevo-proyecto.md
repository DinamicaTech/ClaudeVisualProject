## Summary

El hilo pide de una vez nombre, repositorio de GitHub (si no existe lo crea él; solo si no puede lo pide), carpeta local (opcional, porque la página abre el proyecto desde GitHub), descripción y ficheros de requisitos; añade el repositorio al proyecto de Claude y crea el esqueleto (raíz, `global-rules`, `creative-lab`, `AGENTS.md`, `CLAUDE.md`, `sources/` y las Actions "Open work" y "CVP docs").
Después fija primero la arquitectura (`architecture`) y luego carga los requisitos en el árbol vacío. Los docs se escriben en el idioma del propietario.
