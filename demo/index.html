This browser cannot read a local folder (use Chrome or Edge for that); it can still open a GitHub repository.

Global rules

The rules every thread follows live in the node global-rules. When it holds this page's rules, the prompts only point to it; otherwise they repeat the rules in full. "Update rules" rewrites only its "CVP rules" section; its "Project rules" section is never changed.
GitHub

Open a repository

Token

Without a token the page reads public repositories only, and Rename and Move copy a prompt for a thread instead of writing. With a token it also reads private repositories and commits Rename, Move, the global rules and the node index directly to the default branch. The token is kept only in this browser and sent only to api.github.com. Use a fine-grained token limited to your project repositories, with the permission "Contents: read and write".
